用户关闭全部 Claude Code 终端后，用本地安装入口更新实际插件与启动器，并从已校验的英文备份重新补丁。当前在用 EXE 的 SHA-256 为 `3486fc2246d83c6961e55fac995f8c25c2b310794e6608cbdc2e7aa3b3570991`，与隔离副本一致；receipt 记录 1324 处、revision `f4d514c94e44a3f7`，原版备份指纹不变。启动器连续两次运行 `--help` 均输出中文，前后 EXE 指纹不变；`--version` 为 2.1.289。doctor 保留 `layer4Status=ok`，细分为 `layer4State.code=partial`。

型号标识 `deepseek-flash[1M]` 与按键名 `shift+tab` 保持原样。`with max effort`、`(shift+tab to cycle)` 等动态组合仍未证明可安全原位替换，未作为本次完成项。

11 个帮助面共 **41 条显示审计警告**，不是 41 个独立字符串：主帮助 2 条（动态拼接/参数取值），`mcp --help` 19 条（示例、get/list 说明和部分文案位于非可安全原位替换的结构），`plugin --help` 20 条（`eval` 长段说明跨池宽并含安全语义）。这些内容没有放宽校验或以短到失真的译文硬塞进字节码。

真实交互界面仍观察到英文：首次信任目录说明、auto/manual/plan mode 状态提示、内置 `/code-review` 描述、部分模型标签/快捷键说明，以及退出后的恢复会话提示。它们多为动态组合、用户/供应商模型描述或不在当前安全显示池机制中的字符串；因此本版本为**部分汉化**，不是百分之百中文。

权限确认画面和真实日常请求未在本次自动化流程中触发；由用户在正常使用时完成一次请求后观察确认。Linux/macOS 仅做静态/现有自动测试，不在本报告中宣称实机验证。

## 交付与回退

安装包包含安装、诊断、卸载和 `rollback-local.ps1`。私人备份不放入 ZIP，也不提交到仓库；执行回退时需传入实际备份目录。回退脚本先核对当前 EXE、设置、注册表和启动器的安装后指纹；如果 Claude Code 或用户设置后来发生变化，拒绝覆盖。供应商凭据、会话数据和 CC Switch 配置未写入安装包。
